## 1. 한국어 포지셔닝 확정 - 완료

- [x] 제품 기간을 `30일`이 아니라 `BASIC·STANDARD·HARD 각 30일, 기본 90일`로 설명
- [x] 제품 카테고리를 `동기부여 앱`보다 `자기통제 루틴 프로그램`으로 정의
- [x] 핵심 약속 한 문장 확정
- [x] 앱 이름 확정: `ALPHA - 90일 자기통제`
- [x] 스토어에서 사용할 핵심어 5개 확정
- [x] 남성적이고 단호한 톤과 과장 없는 기능 설명의 균형 승인

완료 기준:

- 사용자와 팀원이 앱을 같은 한 문장으로 설명할 수 있다.
- `90일`, `3단계`, `루틴·기록`, `자기통제`의 관계가 오해 없이 전달된다.
- 앱에서 실제 제공하지 않는 성과나 변화를 약속하지 않는다.

현재 추천 기준:

- 제품 정의: `BASIC부터 HARD까지 이어지는 90일 자기통제 루틴 프로그램`
- 핵심 약속: `90일 동안 루틴을 지키고 기록하며 스스로의 기준을 완성한다.`
- 앱 이름: `ALPHA - 90일 자기통제`
- 핵심어: `자기통제`, `루틴`, `습관`, `자기관리`, `기록`

확인 결과:

- App Store와 Google Play 모두 한국 가격 `KRW 4,400`, 공개 버전 `1.0.3`, 데이터 수집 없음으로 확인했다.
- 10개 현지화 대표 국가의 공개 판매를 확인했다. Google Play는 중국 본토 판매 페이지가 없으며, 전체 콘솔 국가 선택은 인증 후 확인해야 한다.
- Android `1.0.4 (4)` release AAB를 새 업로드 키로 서명했다. 서명 일치와 release 병합 Manifest의 차단 권한 제거를 확인했다.
- Apple은 건강·웰니스 주제를 유지하고 잘못된 무기 답변을 제거했다. Google Play 건강 앱 선언은 `Activity and Fitness`가 맞다.
- 개인정보·지원 URL은 정상이다. 마케팅 페이지의 오래된 30일·출시 준비 문구는 로컬 소스에서 수정했지만 웹 저장소의 다른 미커밋 작업 때문에 배포하지 않았다.
- 상세 근거: `release/privacy-policy-price-validation-2026-08-06.md`

App Store Connect 확인 결과:

- 앱 이름 `ALPHA - 90일 자기통제`, 부제 `90일로 네 인생을 다시 세워라`를 포함한 한국어 필드가 모두 저장됐다.
- 기본 카테고리는 `Productivity`, 보조 카테고리는 `Lifestyle`이다.
- 잘못 남아 있던 무기 관련 연령 답변을 제거했고, App Store 연령 등급은 `4+`다.
- 10개 언어 스크린샷 60장은 `APP_IPHONE_67` 세트에서 모두 처리 완료됐다.
- `1.0.4 (18)` Archive를 검증·업로드하고 빌드에 연결했다. 현재 버전 상태는 `WAITING_FOR_REVIEW`이며 수동 출시 방식이다.

Google Play 확인 결과:

- 10개 언어의 제목·짧은 설명·전체 설명을 반영하고 새 편집 세션에서 저장값을 재조회했다.
- 10개 언어 스크린샷 60장은 서버 SHA-256과 로컬 파일 해시가 모두 일치한다.
- 앱 아이콘과 피처 그래픽은 기존 라이브 파일이 로컬 원본과 이미 같아 재업로드하지 않았다.
- 서비스 계정 JSON 키 대신 Google Cloud 서비스 계정 impersonation을 사용한다.
- `1.0.4 (4)` AAB는 로컬에서 새 업로드 키로 서명·검증했다. 새 인증서의 업로드 키 재설정 요청은 제출했으며 현재 Google 승인 대기 중이다.
- 키 재설정 승인 전이므로 AAB, 출시 트랙, 프로덕션 릴리스는 변경하지 않았다.
- Google Play 한국 공개 페이지에서 새 이름과 짧은 설명 노출을 확인했다. 프로덕션 바이너리는 `1.0.3 (3)` 그대로다.
