# ALPHA 스토어 스크린샷 V2

제작일: 2026-08-06
상태: 한국어 시각 검토안

## 구성

- 1~3장: 앱 UI 없이 하나로 이어지는 검정 계단 파노라마와 브랜드 문장
- 4~6장: 휴대폰 목업 없이 실제 앱 화면에서 잘라낸 컴포넌트
- 공통: 검정, 흰색, 빨강만 사용하고 `ALPHA`, 역할명, 페이지 번호의 위치를 통일
- 원칙: 생성한 가짜 UI나 확인되지 않은 성과 문구를 사용하지 않음

## 문구와 화면

1. `90일로` - 자기통제의 시작
2. `네 인생을` - 오늘을 끝내는 반복
3. `다시 세워라.` - BASIC · STANDARD · HARD
4. `오늘을 끝내라.` - 오늘의 불씨, 요약, 루틴, 완료 버튼
5. `완료도 실패도 기록하라.` - 연속 완료, 과정 진행률, 일별 기록
6. `끝까지 기준을 높여라.` - BASIC 진행률, 현재 단계, 과정 단계
