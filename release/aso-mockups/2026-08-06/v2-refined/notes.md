# ALPHA V2 정제본

상태: 2026-08-06 한국어 iOS·Android 스크린샷 최종 승인.

- iOS 제출용: `release/screenshots/upload/ko`
- Google Play 제출용: `release/google-play/screenshots/ko-KR`

## 유지한 것

- 앞 3장의 계단 파노라마와 `90일로 → 네 인생을 → 다시 세워라` 흐름
- 뒤 3장의 실제 앱 컴포넌트 중심 구성
- 검정, 빨강, 흰색의 브랜드 대비

## 바꾼 것

- 파노라마를 확대해 인물과 계단을 키우고 빈 하늘의 비중을 줄였다.
- 헤드라인을 키우고 앱 아이콘과 ALPHA 표기를 하나의 고정된 브랜드 영역으로 정리했다.
- 페이지 번호와 잡지식 보조 라벨을 제거했다.
- 뒤 3장은 중복되는 UI를 줄이고 `오늘`, `기록`, `과정`의 핵심 컴포넌트만 실제 화면에서 잘라 배치했다.
- 컴포넌트 간격, 테두리, 그림자 강도를 통일했다.
