# ALPHA Magazine 방향성 초안

Updated: 2026-07-10

## 상태

이 문서는 리셋 초안이다.

기존 매거진 캘린더, 첫 피드 구성, 제작 가이드, Day별 제작팩은 방향 합의보다 실행안이 먼저 커져서 제거했다.

지금 필요한 것은 게시물 개수가 아니라 **어떤 매거진이 될 것인지**를 먼저 맞추는 것이다.

## 한 줄 가설

ALPHA Magazine은 동기부여 계정도, 흔한 알파메일 계정도 아니다.

핵심은 아래 문장이다.

```text
몰라서 못 하는 게 아니다.
알면서도 못 닫는 상태다.
```

## 우리가 만들려는 것

ALPHA Magazine은 ALPHA 앱의 유입 채널이지만, 처음부터 앱 광고처럼 보이면 안 된다.

먼저 독립적인 자기통제 매거진으로 보여야 한다.

매거진이 만들어야 하는 것:

- 자기 상태를 알아보게 만드는 언어.
- 계속 이렇게 살면 안 된다는 압박.
- 오늘 바로 할 수 있는 작은 행동.
- 가짜 부자, 여성혐오, 허세 동기부여와 다른 신뢰.
- 나중에 앱이 등장했을 때 자연스럽게 이어지는 필요성.

## 타깃

1차 타깃:

- 18-26세 남성.
- 대학생, 취준생, 사회초년생, 전역 후 복귀자, 시험 준비생.
- 폰, 수면, 방, 몸, 돈, 자신감이 조금씩 무너지는 걸 느끼는 사람.
- 정보가 부족한 게 아니라 실행 구조가 없는 사람.

사용자 속마음:

```text
나도 이렇게 살면 안 되는 건 안다.
근데 혼자서는 계속 미룬다.
```

## 톤

써야 하는 톤:

- 차갑게.
- 짧게.
- 구체적으로.
- 행동으로 끝나게.
- 자기합리화를 찌르게.

피해야 하는 톤:

- 여성혐오.
- 픽업/연애 지배 프레임.
- fake wealth.
- "진짜 남자라면" 식 문장.
- 사람을 망가뜨리는 자기혐오.
- 예쁜 동기부여 명언.
- 앱이 아직 못 하는 것을 과장하는 문장.

톤 원칙:

```text
습관은 세게 찌르고,
사람은 망가뜨리지 않는다.
```

## 첫 버전의 콘텐츠 범위

처음부터 돈, 관계, 앱 CTA까지 다 열지 않는다.

첫 버전은 아래 4개만 본다.

### 1. 아침 통제

핵심 질문:

```text
눈뜨고 처음 10분을 누가 가져가는가?
```

예시 주제:

- 침대 위 폰.
- 알람 끄고 다시 눕기.
- 첫 스크롤.
- 물 500ml.
- 일어나자마자 첫 행동.

### 2. 눈에 보이는 통제

핵심 질문:

```text
내 통제력이 눈에 보이는가?
```

예시 주제:

- 침대.
- 방.
- 책상.
- 옷.
- 가방.

### 3. 몸 통제

핵심 질문:

```text
생각보다 먼저 몸이 움직이는가?
```

예시 주제:

- 푸쉬업.
- 걷기.
- 샤워.
- 자세.
- 수면.

### 4. 도파민 통제

핵심 질문:

```text
쉬는 척하면서 시작력을 잃고 있지 않은가?
```

예시 주제:

- 쇼츠/릴스.
- 게임 루프.
- 알림.
- 자기 전 폰.

돈과 관계는 나중에 확장한다. 지금은 매거진의 첫 인상이 흐려질 수 있다.

## 게시물 공식

각 게시물은 아래 구조를 따른다.

```text
1. Hook: 아픈 진실 한 문장.
2. Mirror: 사용자가 실제로 하는 행동.
3. Reframe: 정보 문제가 아니라 통제 구조 문제라는 해석.
4. Action: 오늘 할 수 있는 작은 행동 하나.
5. Close: ALPHA 세계관과 연결되는 마무리.
```

예시:

```text
Hook:
너는 시간이 없는 게 아니다.

Mirror:
눈뜨자마자 폰을 보면 하루의 첫 명령을 넘긴다.

Reframe:
문제는 의지가 아니라 구조다.

Action:
오늘은 폰을 방 밖에 두고 자라.

Close:
처음 10분을 되찾아라.
```

## 앱과의 관계

초기 매거진은 앱을 바로 팔지 않는다.

순서는 이쪽이 맞다.

```text
매거진: 문제를 정확히 말한다.
사용자: "이거 내 얘기다"라고 느낀다.
매거진: 오늘 할 수 있는 행동 하나를 준다.
앱: Day 1 이후 도망가지 않게 해주는 시스템으로 등장한다.
```

초기 CTA:

```text
저장하고 오늘 해라.
```

나중에 쓸 수 있는 앱 브릿지:

```text
Day 1은 누구나 안다.
Day 2부터는 시스템이 필요하다.
```

앱의 Day progression, closing flow, 결제 구조가 믿을 만해지기 전까지 다운로드/결제 카피는 밀지 않는다.

## 비주얼 방향

초기 방향:

- 실제 일상 행동 사진.
- 검은 편집 매거진 레이아웃.
- 흰색 큰 한글 헤드라인.
- 빨간 ALPHA 포인트 1개.
- 앱 스크린샷은 최소화.

피할 것:

- ALPHA 캐릭터를 인스타 메인 정체성으로 쓰는 것.
- 럭셔리/플렉스 이미지.
- 웰니스 인플루언서처럼 보이는 스톡 사진.
- 동기부여 포스터 같은 디자인.

비주얼 원칙:

```text
이미지는 분위기고,
문장이 자산이다.
```

## 아직 하지 않을 것

지금은 하지 않는다.

- 14일 캘린더.
- 첫 9개 피드 확정.
- Day별 제작팩.
- 앱 다운로드 CTA.
- 결제/페이월 카피.
- 돈/관계 주제 확장.
- 외부 에셋 최종 수집.

이것들은 매거진 목소리를 합의한 뒤에 만든다.

1. 첫 버전은 `차가운 편집 매거진`에 가까워야 하나, `직접 명령하는 계정`에 가까워야 하나?
2. 계정명은 `ALPHA Magazine`, `ALPHA Day 1`, 다른 이름 중 무엇이 맞나?
3. 초반 게시물에서 남성을 직접 말할까, 아니면 주제와 톤으로만 드러낼까?
4. 첫 기둥은 아침 통제, 눈에 보이는 통제, 몸 통제, 도파민 통제 중 무엇으로 갈까?
5. 훅은 어디까지 세게 가도 되는가?
