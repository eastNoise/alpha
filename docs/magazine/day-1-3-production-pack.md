# ALPHA Magazine Day 1-3 Production Pack

Updated: 2026-07-10

## Purpose

This pack turns the first 3 days of ALPHA Magazine into publish-ready production specs.

It is written for whoever makes or posts the actual Instagram assets. The app implementation stays separate.

## Shared Rules

- Keep the cover hook short enough to read from the profile grid.
- Use one red accent and one clear action.
- Avoid motivational filler.
- Do not sell the app yet.
- If an image uses stock, log the source in `asset-source-register.md`.
- If a caption is edited, preserve the core action.

## Day 3: First Reel

### Publishing Slot

```text
Day 3
Format: Reel
Pillar: Routine / Dopamine
Primary metric: Reach
Secondary metric: Profile visits
```

### Reel Cover

```text
너는 일어나자마자
하루를 넘긴다
```

Footer:

```text
첫 10분을 지켜라.
```

### Script

Length target: 10-14 seconds.

```text
눈뜨자마자 폰을 보면
오늘의 첫 명령을 남에게 넘긴다.

알림.
쇼츠.
메시지.

일어나기도 전에 끌려간 거다.

내일은 첫 10분만 지켜라.
```

### Shot List

1. 0.0-1.5s
   - Dark room or alarm close-up.
   - Text: `눈뜨자마자 폰을 보면`

2. 1.5-3.5s
   - Phone screen glow or hand reaching for phone.
   - Text: `오늘의 첫 명령을 넘긴다`

3. 3.5-6.5s
   - Fast text cuts.
   - Text sequence: `알림` / `쇼츠` / `메시지`

4. 6.5-9.5s
   - Back to dark room or blank black screen.
   - Text: `일어나기도 전에 끌려간 거다`

5. 9.5-14s
   - Red ALPHA frame.
   - Text: `내일 첫 10분만 지켜라`

### Caption

```text
아침의 첫 10분은 작아 보인다.
근데 그 10분을 빼앗기면 하루가 계속 밀린다.

내일은 폰보다 물을 먼저 잡아라.
```

### On-Screen Text Style

- White text.
- Black background or dark footage.
- Red word only for one key phrase: `첫 10분`.
- No more than 8 Korean words per frame.
- Cut every 1.5-2 seconds.

### Audio Direction

Use:

- Low, minimal, percussive audio.
- No cheerful motivational music.
- No meme audio for the first launch week.

### Alt Text / Accessibility Caption

```text
어두운 아침과 휴대폰 사용 장면을 빠르게 보여주며, 눈뜨자마자 휴대폰을 보면 하루의 첫 명령을 남에게 넘긴다는 메시지를 전달하는 ALPHA Magazine 릴스.
```

## Posting Checklist For Day 1-3

Before publishing:

- Cover hook readable from grid.
- Caption has one action.
- Story poll is prepared.
- Asset source is recorded.
- No hard app sell.
- No "alpha male" cliche.
- No stock image watermark.
- Post file exported at the right size.
- First comment is not needed unless hashtags are tested separately.
